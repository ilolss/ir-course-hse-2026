# ДЗ 3. Обучение ранжированию

Kaggle: `ilolss`.

Public nDCG@10: **0.62426**. Бейзлайн: **0.61621**.

Модель: `CatBoostRanker` на всех 67 признаках.

Лучшие параметры: `loss_function="YetiRank"`, `depth=6`, `learning_rate=0.05`,
`iterations=414`, `random_seed=42`, `thread_count=4`.

Валидация — 20% запросов из train, разбиение с seed 42. Число итераций выбрано
по `NDCG:top=10;type=Exp` с максимумом 1000 итераций и ранней остановкой через
100 итераций без улучшения. Затем модель обучается на всём train.
